# Visual review

1. Open the URL with the Playwright MCP at 1440x900, full-page screenshot.
2. Repeat at 390x844 (mobile).
3. If the page has a theme toggle or prefers-color-scheme, capture both themes.
4. Scroll in steps and capture any animation states.
5. Save to `research/moodboard/<site-or-page>/` with descriptive file names.
6. Show the screenshots and write a critique: hierarchy, palette, typography,
   spacing, motion, accessibility, and what TA-LLM should adopt or avoid.
