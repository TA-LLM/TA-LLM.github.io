# TA-LLM website

Source of the website of the research project
**TA-LLM — Large Language Models: a matter of time?** (MUR FIS 2, Politecnico di Torino).

- `CLAUDE.md` — project memory for Claude Code (context, design system, rules)
- `.mcp.json` — shared MCP servers: Playwright (browser), Context7 (docs), Figma
- `.claude/agents/` — specialized subagents (design research, content, front-end, QA)
- `.claude/skills/` — reusable procedures (add a publication, visual review)
- `research/` — moodboard screenshots and design notes
- `sources/private/` — private drafts, git-ignored, never published
